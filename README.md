# Home Hub

Home Hub объединяет Windows-ПК, Android-телефон и Android TV в домашней сети. Телефон служит пультом управления, а Windows-приложение — центром работы с подключёнными устройствами.

## Возможности

- Сопряжение устройств с проверкой отпечатка сертификата.
- Управление ПК с телефона: тачпад, клавиатура, громкость, мультимедиа и яркость мониторов.
- Просмотр экранов и удалённое управление при наличии необходимых разрешений.
- Работа с Android TV и переключение между подключёнными устройствами.

Доступность функций зависит от оборудования, версии ОС и выданных разрешений.

## Скачать и установить

Установщики публикуются в [GitHub Releases](https://github.com/AlemusSs/Home-Hub/releases). Выберите файл для своей платформы:

| Платформа | Инструкции | Файл |
| --- | --- | --- |
| Windows 10/11 x64 | [Windows](Windows/) | HomeHub-Windows-VERSION-Setup.exe |
| Android-телефон (Android 8+) | [Android Phone](Android-Phone/) | HomeHub-Android-VERSION.apk |
| Android TV (Android 8+) | [Android TV](Android-TV/) | HomeHub-TV-VERSION.apk |

В описании выпуска указываются версия, дата и изменения; SHA256SUMS.txt содержит контрольные суммы. Не устанавливайте APK для другой платформы.

## Начало работы

1. Установите Home Hub на устройства и подключите их к домашней сети.
2. Откройте сопряжение на ПК и добавьте ПК в приложении телефона.
3. Введите показанный код и сверьте отпечаток сертификата.
4. Выдайте только необходимые разрешения. Для захвата экрана Android показывает системный запрос; для удалённого ввода может потребоваться служба специальных возможностей.

Сохраняйте данные приложения при обновлении: APK устанавливается поверх прежней версии с той же подписью. Android может запросить разрешение установки из выбранного источника и подтверждение обновления.
