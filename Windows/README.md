# Home Hub — Windows

Закройте Home Hub и запустите установщик. Выберите существующую папку установки для обновления. Данные сопряжений сохраняются. Требуется Windows 10/11 x64.

Установщик: `HomeHub-Windows-VERSION-Setup.exe` в [Releases](https://github.com/AlemusSs/Home-Hub/releases).

Актуальный локальный выпуск: **0.3.4**, дата сборки **08.11.2026**. Дату публикации, доступность файла и SHA-256 смотрите в конкретном выпуске. Здесь хранятся инструкции; установочные файлы размещаются как вложения Releases.
