# Home Hub — Android Phone

Установите APK на телефон поверх существующего Home Hub. Не удаляйте приложение перед обновлением: удаление стирает локальные данные. Требуется Android 8 или новее.

Установщик: `HomeHub-Android-VERSION.apk` в [Releases](https://github.com/AlemusSs/Home-Hub/releases).

Актуальный локальный выпуск: **0.3.4**, дата сборки **08.11.2026**. Дату публикации, доступность файла и SHA-256 смотрите в конкретном выпуске. Здесь хранятся инструкции; установочные файлы размещаются как вложения Releases.
