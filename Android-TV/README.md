# Home Hub — Android TV

Установите APK на приставку поверх существующего Home Hub TV. Подтвердите системную установку. Для удалённого управления включите службу Home Hub TV в специальных возможностях. Требуется Android 11 или новее.

Установщик: `HomeHub-TV-VERSION.apk` в [Releases](https://github.com/AlemusSs/Home-Hub/releases).

Дату публикации и SHA-256 смотрите в [текущем выпуске](https://github.com/AlemusSs/Home-Hub/releases/latest).
